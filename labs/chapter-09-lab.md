# Chapter 9 Lab: Implementing CI/CD with Git Folders and Databricks Asset Bundles

**Estimated time:** 20 minutes

## Exercise

Initialize a Databricks Asset Bundle using the CLI, define dev and prod targets with different workspace paths, and deploy the bundle to the dev target using databricks bundle deploy.

## Key takeaway

Git folders handle source control and collaboration, while Databricks Asset Bundles handle the actual, repeatable deployment of jobs and pipelines across environments.
