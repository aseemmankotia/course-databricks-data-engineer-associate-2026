# Chapter 1 Lab: Platform Architecture, Workspace, and Compute

**Estimated time:** 15 minutes

## Exercise

Create an all-purpose cluster and a job cluster in the Databricks workspace, run the same notebook on both, and compare startup time and cost implications in the cluster event log.

## Key takeaway

Choose compute type based on workload pattern — job clusters for scheduled, cost-controlled runs and all-purpose clusters for interactive shared work.
